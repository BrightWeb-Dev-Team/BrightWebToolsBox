中文菜单栏工具，整合屏幕轻敲动作、灵动岛与关于本机显示修改。
设置 → 灵动岛与机型：选择仅灵动岛、仅关于本机或两项，独立启用与恢复。

关于本机显示：14/16 英寸PROLED XDR 显示屏、Apple M5 Max、128 GB、灵动岛机型图标。
仅改变显示，真实硬件保持原样。系统增强功能需要匹配的开发工具与进程调试权限；软件不会自动修改 SIP。
